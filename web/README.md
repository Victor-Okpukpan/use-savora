# Savora — web

Next.js 16 (App Router) frontend for the Savora ajo program. Talks to the
deployed devnet program directly through a `@solana/kit` client generated by
Codama; Privy handles email / social / wallet sign-in with its own prebuilt UI.

See the repo root [`README.md`](../README.md) for the program, the on-chain
deployment record, and how the two fit together.

## Environment

Copy `.env.example` to `.env.local` and fill it in:

```bash
NEXT_PUBLIC_PRIVY_APP_ID=                         # dashboard.privy.io (free)
NEXT_PUBLIC_SOLANA_RPC_URL=                       # a dedicated devnet RPC (Alchemy / Helius / Triton)
NEXT_PUBLIC_SOLANA_RPC_SUBSCRIPTIONS_URL=         # the same provider's wss:// URL
```

The public `https://api.devnet.solana.com` works for light use but rate-limits
under load. `NEXT_PUBLIC_*` values are baked into the client bundle at build
time — restrict the RPC key to your domain in the provider dashboard.

The program ID and devnet USDC mint are compiled in via
[`src/lib/savora/config.ts`](src/lib/savora/config.ts); no env var for them.

## Commands

```bash
pnpm dev                          # http://localhost:3000
NEXT_PUBLIC_SAVORA_DEMO=1 pnpm dev # full UI from fixtures (src/lib/savora/demo.ts) — no chain, no funds
pnpm build && pnpm start          # production build + serve
pnpm exec eslint src              # lint
pnpm exec tsc --noEmit            # typecheck
```

Regenerate the on-chain client after any program change:

```bash
cd .. && anchor build && pnpm codegen   # writes web/src/generated/
```

## Deploy (Vercel)

Run from this folder — it auto-detects Next.js, so no root-directory config.

```bash
pnpm add -g vercel
vercel login
vercel                                                   # first deploy → preview URL

vercel env add NEXT_PUBLIC_PRIVY_APP_ID production        # paste your Privy app id
vercel env add NEXT_PUBLIC_SOLANA_RPC_URL production      # paste your https:// RPC URL
vercel env add NEXT_PUBLIC_SOLANA_RPC_SUBSCRIPTIONS_URL production  # paste your wss:// RPC URL

vercel --prod                                            # → live URL
```

Then in the **Privy dashboard** → your app → *Allowed origins*, add the
deployed URL, or sign-in will fail.

Redeploys: `vercel --prod`.

## Routes

| | |
|---|---|
| `/` | Landing (marketing motion register) |
| `/app` | Dashboard — Circles · Activity · Profile tabs |
| `/app/new` | Create a circle |
| `/g/[address]` | A circle: roster, rotation, contribute / crank, activity |
| `/docs` | How it works, in plain language and at the protocol level |

## Theme

Follows the OS on a fresh tab. The header toggle flips light ↔ dark and the
choice is kept in `sessionStorage` — it survives refreshes and in-tab
navigation, and resets in a new tab. See [`src/lib/theme.ts`](src/lib/theme.ts).
